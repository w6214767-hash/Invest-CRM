# Скоринг участков

## Рыночная часть

1. Для географического кластера формируется набор активных `comps`.
2. Считается медианная цена за сотку.
3. Дисконт лота: `(медиана − цена_лота_за_сотку) / медиана × 100`.

## Итоговый балл

Все компоненты ограничиваются диапазоном 0–100. Отрицательный дисконт не даёт бонуса.

```text
Score = 0,35 × Discount + 0,20 × Liquidity + 0,15 × Location
      + 0,10 × Docs + 0,10 × Utility + 0,10 × SellerUrgency
```

`SellerUrgency` строится на фразах «срочно», «торг», «нужны деньги». Анализ также выделяет флаги риска: отсутствие кадастрового номера, сомнительные документы, ограничения и неподтверждённые коммуникации.

Скоринг является инструментом приоритизации, а не ценовым предложением или юридическим заключением.

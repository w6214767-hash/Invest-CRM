# Безопасное и корректное использование Авито

## Лимиты и доступ

- Используйте только одобренное приложение Avito Business API и те методы, которые доступны вашему договору.
- Консервативно ограничивайте частоту запросов. Клиент проекта по умолчанию выдерживает интервал 0,25 секунды; реальный лимит необходимо подтвердить в кабинете Авито.
- Не храните OAuth-токены в Git, логах или frontend. Секреты находятся только в `.env` на сервере.

## Human-in-the-loop

- Первый контакт должен быть черновиком или подтверждаться менеджером в режиме `draft`/`assisted`.
- Автоматический сценарий прекращается при упоминании кадастрового номера, торге более 7%, готовности к авансу, признаке юридического риска или раздражении продавца.
- Каждое изменение стадии переговоров записывается в `negotiation_events`.

## Что нельзя автоматизировать без проверки

- Нельзя обещать цену, аванс, задаток, договор или юридическую чистоту участка.
- Нельзя имитировать человека, обходить ограничения платформы или отправлять массовые нерелевантные сообщения.
- Нельзя считать текст объявления юридической экспертизой. Кадастровые сведения, права, ограничения, ВРИ и коммуникации проверяет уполномоченный сотрудник по первичным источникам.
- Перед продуктивным включением вебхуков добавьте проверку подписи по формату, предоставленному Авито.

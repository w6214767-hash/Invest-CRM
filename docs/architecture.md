# Архитектура

```text
React/Vite ──> Nginx ──> FastAPI ──> PostgreSQL
                     │        │
                     │        ├── Redis / очередь задач
                     │        ├── Avito Business API
                     │        ├── Bitrix24 REST webhook
                     │        ├── Telegram Bot API
                     │        └── Hermes Agent
                     │
                     └── Worker: синхронизация, пересчёт, чаты, дайджест
```

## Принципы

- FastAPI предоставляет версионированный HTTP API с префиксом `/api/v1`.
- PostgreSQL хранит нормализованные карточки лотов, продавцов, диалогов, предложений и сделок. JSON-поля оставлены для исходных payload и аудита событий.
- Нginx публикует SPA и передаёт `/api` в backend; база и Redis из сети не публикуются.
- Воркер запускает повторяемые фоновые операции. `workers/scheduler.py` хранит нейтральное расписание, пригодное для ARQ или Celery-обёртки.
- Все исходящие сообщения должны проходить установленный режим и правила эскалации.

## Границы интеграций

Avito и Hermes оформлены отдельными клиентами, чтобы изменение их контрактов не влияло на доменную логику. Bitrix24 получает данные только после создания локальной сделки и проверки менеджером.

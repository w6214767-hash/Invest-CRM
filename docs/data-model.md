# Модель данных

| Сущность | Назначение | Ключевые связи |
|---|---|---|
| `users` | Сотрудники CRM | исполнитель `tasks` |
| `sellers` | Продавцы из Авито | один продавец — много `listings`, `chats` |
| `listings` | Земельные участки | связаны с продавцом, компсами, оценками, офферами, сделками |
| `comps` | Сопоставимые лоты | формируют медиану кластера |
| `valuations` | Зафиксированные оценки | история скоринга лота |
| `chats`, `messages` | Диалоги Авито | связаны с лотом и продавцом |
| `negotiation_events` | Аудит стейт-машины | переход переговорной стадии лота |
| `offers` | Финансовые предложения | могут стать основой сделки |
| `deals` | Инвестиционные сделки | содержат ID Bitrix24 после выгрузки |
| `tasks` | Ручные действия менеджера | относятся к лоту или сделке |
| `pipeline_stages` | Настройка локальной воронки | поддерживает интерфейс CRM |

Перечисления хранят статус объявления, стадию переговоров, тип продавца и стадию сделки. Важные поля имеют индексы: внешние ID Авито/Bitrix24, телефоны, география и внешние ключи.
